# Raja Kumar Singh - Portfolio

A modern, responsive portfolio website showcasing my work as a Full Stack Developer. Built with cutting-edge technologies and featuring smooth animations, glassmorphism design, and full dark/light mode support.

## ✨ Features

- 🎨 **Modern UI/UX** - Glassmorphism design with smooth animations
- 🌓 **Theme Toggle** - Seamless dark/light mode switching with persistence
- 📱 **Fully Responsive** - Optimized for all devices (mobile, tablet, desktop)
- ⚡ **High Performance** - Built with Vite for lightning-fast development and builds
- 🎭 **Advanced Animations** - Framer Motion for delightful micro-interactions
- 🎯 **Accessible** - WCAG compliant with proper semantic HTML
- 🔥 **Modern Stack** - React, TypeScript, Tailwind CSS

## 🚀 Tech Stack

### Frontend
- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **Tailwind CSS v4** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **Lucide React** - Icon library

### UI Components
- **Radix UI** - Accessible component primitives
- **Shadcn/ui** - Re-usable component library
- **Sonner** - Toast notifications

## 🛠️ Installation & Setup

### Prerequisites
- Node.js (v18 or higher)
- pnpm (or npm/yarn)

### Steps

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   pnpm install
   # or
   npm install
   ```

3. **Start development server**
   ```bash
   pnpm dev
   # or
   npm run dev
   ```

4. **Open in browser**
   Navigate to `http://localhost:5173`

## 📦 Build for Production

```bash
pnpm build
# or
npm run build
```

The production-ready files will be in the `dist/` directory.
